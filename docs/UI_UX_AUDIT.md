# Traveling · UI/UX 审计与提升记录

> 审计日期：2026-10-05 ｜ 方法：代码级走查 + 数据一致性核对，参照 5 份公开 UI/UX Skill 规则库（WCAG 2.2 AA、Nielsen 启发式、反 AI-slop、诚实呈现原则）
> 结论先行：**设计系统成熟度很高，问题不在视觉，而在「数据可信度」与「无障碍下限」两类。本轮已修复 4 项，剩余 3 项需要站长决策。**

---

## 一、审计结论

这个站的设计令牌体系（`global.css` @theme + `docs/personal-site-implementation-spec.md`）在个人站里属于最高一档：三层字体分工（衬线标题/无衬线正文/等宽元信息）、1px 发丝线层级、打印样式、`prefers-reduced-motion` 降级、skip-link、`aria-current` 导航态、构建期零 JS 首页——外部 Skill 清单里的检查项几乎逐条命中。**不需要任何视觉重设计。**

真正的问题有两类：

| 类别 | 问题 |
|---|---|
| **数据可信度** | 首页数字带手写「340 张照片」，管线产物实际 **592 张**——对一个以「自动化管线、诚实数字」为卖点的站，首页第一屏的数字与事实脱节是最伤信任的缺陷 |
| **无障碍下限** | 元信息色 `ink-3 #8c8c96` 对纸底对比度仅 **3.2:1**，而它承载的 meta/时间戳是 11.5px 小字号——低于 WCAG AA 4.5:1 |

## 三、复核确认「不需要动」的资产

1. **整体视觉方向**（纸白 + 发丝线 + 衬线大标题 + 唯一暗色岛 TravelIsland）——克制、统一、有明确规格来源；
2. **零 JS 首页架构**：`index.astro` 服务端渲染，全站仅地图 / 小地图 / 灯箱 / 文章目录 4 个 React island；
3. **Base.astro 布局层**：skip-link、aria-expanded 汉堡菜单、canonical/OG、`/` 聚焦搜索快捷键、返回顶部 rAF 节流——全部达标；
4. **打印样式**（A4 排版、链接显示地址、隐藏交互设施）——同类站点几乎没人做；
5. **prose-editorial 正文排版**：代码块工具条、callout/aside-note/blockquote 全套落样式；
6. **全站 `<img>` 均有 alt**（逐组件核过）。
